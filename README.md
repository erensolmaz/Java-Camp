## ✨ Features

- **Week 1** – variables, data types, conditionals, loops, arrays, strings and mini projects (prime numbers, perfect numbers, number guessing…)
- **Week 2** – classes, methods, overloading, OOP basics, inheritance
- **Week 3** – abstract classes, interfaces, overriding, N-Layered architecture
- **SQL** – week 3 queries and sample database files
- **Spring Boot** – `rentACar` REST API with a layered structure (Brand entity, service, repository, controller)

## 🚀 Getting Started

Each example is a small standalone Java program. Open the folder in IntelliJ IDEA / VS Code and run `Main.java`.

For the Spring project:
```bash
cd spring/rentACar
./mvnw spring-boot:run
```
